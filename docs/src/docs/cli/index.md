The Avon CLI is the command-line interface for working with Avon from a terminal.

## What it’s for

- Install and update the CLI on your machine
- Authenticate against your Avon environment
- Run common course and project commands without the browser

## In this section

| Page                      | What it’s for                   |
| ------------------------- | ------------------------------- |
| [Install](/cli/install)   | Get the CLI on your machine     |
| [Commands](/cli/commands) | Reference for the main commands |

## Prerequisites

- A supported terminal (macOS, Linux, or WSL)
- Access to your institution’s Avon deployment where required
