# Avon docs

Public mirror of the Avon documentation site, served at
[docs.avon.ac](https://docs.avon.ac).

`docs/` is synced automatically from the Avon monorepo and deployed to GitHub
Pages by [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Don't
edit files in `docs/` here - changes are overwritten on the next sync.
